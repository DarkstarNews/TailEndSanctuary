# Tail End Sanctuary

Website for **Tail End Sanctuary** — a sanctuary giving lifelong care to senior stray dogs in the Lake Chapala area of Mexico.

🌐 **Live site: https://tailendsanctuary.org**

A plain static website (hand-written HTML + CSS, no build step). Hosted free on GitHub Pages — pushing to the `main` branch publishes the site.

📘 **New here? Start with [DEVELOPER-GUIDE.md](DEVELOPER-GUIDE.md)** — hosting, DNS, how to publish changes, how to swap photos and text, and how to take over ownership.

*every tail deserves a happy ending*.
