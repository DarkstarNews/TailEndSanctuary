# Tail End Sanctuary

Senior dog rescue sanctuary — Lake Chapala, Mexico. Live at [tailendsanctuary.org](https://tailendsanctuary.org).

## Editing the site

- **Founders (Juanita, Ronni, Jena):** use the friendly editor at
  [tailendsanctuary.org/editor](https://tailendsanctuary.org/editor) — see `EDITOR-GUIDE.md`.
- **Developers:** page text/photos live in `content/content.json`, page markup in
  `templates/`. Edit those (not the root HTML files) and run `node build.js` to
  regenerate the pages. Setup for the editor backend is in `SETUP.md`.
